A simple game created in 3-4 hours for the game jam: "Blink and you'll miss it"
The concept: press the correct key, and it gets faster with each round.

Future plans:
Add visuals, like a retro font (similar to Balatro).
Add background music to make it more immersive.
Introduce distractions like animals or objects appearing on screen edges.
To run the game:


Make sure you have .NET installed. Use Visual Studio Code or any similar IDE to launch it as its a quick game I made in VScode.
